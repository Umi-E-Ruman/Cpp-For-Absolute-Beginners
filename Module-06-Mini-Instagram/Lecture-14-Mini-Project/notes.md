# Lecture 14: Mini Instagram — Complete CRUD Project

## 🎯 Project Overview
This is the capstone project of the course. You will apply everything learned so far (Variables, Loops, Functions, Arrays, Pointers, Conditionals) to build a fully functional command-line application.

A **Mini Instagram** clone that runs in the terminal, using **CRUD** operations and basic authentication.

---

## 🧠 What You'll Learn
- **CRUD Operations:** Create, Read, Update, Delete
- Using **2D Arrays** to store user data
- Using **Pointers** for data traversal
- Menu-driven programming using `switch-case` and `do-while`
- Login and Signup functionality
- How real-world projects are structured

---

## ⚙️ Features Implemented

### 1. Authentication
- **Signup:** Register a new user (stored in arrays)
- **Login:** Verify credentials to access the dashboard

### 2. Dashboard (CRUD)
- **Create:** Add a new friend (Name, Age)
- **Read:** View all friends
- **Read (Specific):** Search for a friend by name
- **Update:** Change a friend's age
- **Delete:** Remove a friend from the list

---

## 💻 Code Structure
*(The full source code is available in `main.cpp`)*

The project uses:
- `do-while` loop to keep the program running
- `switch-case` for the menu options
- `2D char arrays` to store names
- `int arrays` to store ages
