## ➕ 1. Arithmetic Operators
Used for mathematical calculations.

| Operator | Meaning | Example |
|----------|---------|---------|
| `+` | Addition | `a + b` |
| `-` | Subtraction | `a - b` |
| `*` | Multiplication | `a * b` |
| `/` | Division | `a / b` |
| `%` | Modulus (Remainder) | `a % b` |

*(Note: Integer division vs Float division is covered in detail in the lecture)*

---

## ⚖️ 2. Relational Operators
Used to compare two values. Returns `true` (1) or `false` (0).

- `==` (Equal to)
- `!=` (Not equal to)
- `>` (Greater than)
- `<` (Less than)
- `>=` (Greater than or equal to)
- `<=` (Less than or equal to)

---

## 🧠 3. Logical Operators
Used to combine multiple conditions.

- `&&` (AND) → True if **both** are true
- `||` (OR) → True if **at least one** is true
- `!` (NOT) → Reverses the result (True becomes False)

---

## 🔄 4. Unary Operators
Operate on a single operand.

- `++` (Increment): Increases value by 1
- `--` (Decrement): Decreases value by 1

**Pre vs Post:**
- `++a` (Pre-increment): Increments first, then uses the value.
- `a++` (Post-increment): Uses the value first, then increments.

---

## 📝 5. Assignment Operators
Used to assign values to variables.

- `=` (Assign)
- `+=` (Add and assign: `a += b` is `a = a + b`)
- `-=` (Subtract and assign)
- `*=` (Multiply and assign)
- `/=` (Divide and assign)
- `%=` (Modulus and assign)

---

## 🏆 Operator Precedence
Which operator runs first?
1. `()`, `++`, `--`
2. `*`, `/`, `%`
3. `+`, `-`
4. `<`, `>`, `<=`, `>=`
5. `==`, `!=`
6. `&&`
7. `||`
8. `=`, `+=`, `-=`
