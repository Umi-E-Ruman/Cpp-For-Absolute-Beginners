## 🧠 What is Programming?
Programming is the process of writing instructions for a computer to perform a specific task. Computers don't think on their own; they just follow the exact commands we give them.

## 🍳 Code vs Program vs Software (Cooking Analogy)
To make it easy to understand, think of cooking:
- **Code:** The raw instructions written in a file (e.g., "boil water", "add tea leaves").
- **Program:** The complete recipe containing all those instructions put together.
- **Software:** The final, ready-to-use product (the actual cup of tea you drink).

## 💻 Machine Language vs High-Level Language
- **Machine Language (Low-Level):** Only 0s and 1s. The computer understands this directly, but it is impossible for humans to write complex programs in it.
- **High-Level Language (C++):** Written in English-like words. It is easy for humans to read and write, but it requires a **Compiler** to translate it into Machine Language for the computer to run.

## ⚠️ Syntax vs Semantics
- **Syntax:** The grammar rules of the language. (e.g., Missing a semicolon `;` or a closing bracket `}` causes a syntax error).
- **Semantics:** The meaning of the code. (e.g., Your code runs without errors, but it calculates the wrong result).

## 💬 Comments in Code
Comments are notes written inside the code that the compiler ignores. They are used to explain what the code does.
- `//` is used for single-line comments.
- `/* ... */` is used for multi-line comments.
