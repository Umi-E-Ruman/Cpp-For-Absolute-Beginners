## 🎯 Key Concepts

### 4-Step Problem-Solving System
1. **Understand** — Read the problem 3 times
2. **Input / Output / Process** — Identify what goes in, what comes out, how
3. **Plan** — Write solution in your own language first
4. **Translate to Code** — Convert plan into C++

### Git & GitHub
- Creating GitHub account
- Installing Git
- `git config` (user.name, user.email)
- `git init`, `git add`, `git commit`
- `git push`, `git pull`
- `git status`, `git log`, `git clone`
- `git branch`, `git merge`
- Professional workflow
