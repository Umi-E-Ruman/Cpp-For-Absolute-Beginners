## 🧠 The 4-Step Problem-Solving System

Most beginners fail because they try to code immediately. Here is the repeatable system:

### Step 1: Understand the Problem
- Read the problem statement **3 times**.
- Do not look at the keyboard yet.
- Make sure you understand exactly what is being asked.

### Step 2: Identify Input, Output, and Process
- **Input:** What data is given to you?
- **Output:** What result do you need to produce?
- **Process:** What steps will turn the input into the output?

### Step 3: Write the Solution in Plain Language
- Write the steps in your own words (Urdu/English).
- Example: "If the number divided by 2 leaves a remainder of 0, print 'Even'."
- This is called **Pseudocode** or Algorithm.

### Step 4: Translate to Code
- Now open your editor and convert your plain language steps into C++ syntax.

## 🐙 Complete Git & GitHub Setup

### What is Git?
Git is a **Version Control System**. It tracks changes in your code so you can go back to previous versions if you make a mistake.

### What is GitHub?
GitHub is a **cloud platform** to host your Git repositories online. It is your coding portfolio.

### Essential Git Commands
- `git init` — Initializes a new Git repository
- `git add .` — Stages all changed files
- `git commit -m "message"` — Saves the changes with a message
- `git push` — Uploads local commits to GitHub
- `git pull` — Downloads latest changes from GitHub
- `git status` — Shows the current state of your files
- `git log` — Shows commit history
- `git clone` — Copies a remote repository to your local machine
- `git branch` — Creates a new branch
- `git merge` — Merges branches together

---

## 💡 Key Takeaways
- Always follow the 4-step method before writing code.
- Git is for tracking, GitHub is for sharing.
- Commit often with meaningful messages.
